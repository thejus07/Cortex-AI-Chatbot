# AI Chatbot Setup Agent for Freelancers

A high-end, premium, and extremely interactive single-page web application dashboard designed for freelancers. This application enables you to customize, test in real-time, and deploy context-aware chatbots tailored to your freelance services (Lead Generation, Client Onboarding, FAQ answering).

---

## Key Features

1. **🛠️ Interactive Chatbot Creator**: 
   - Configure identity (bot name and beautiful avatars).
   - Customize personality vibe (Professional, Friendly, Hustler, or Technical Expert) affecting the bot's tone and dialogue dynamically.
   - Choose pre-filled knowledge templates (Web Developer, UI/UX Designer, Copywriter, SEO Consultant) or paste your own custom FAQs, services, and pricing matrices.
2. **🔌 DevOps Deploy Simulator**:
   - Simulated deployment CLI terminal displaying pipeline stages: context vectorization, database linking, webhook handshake, and edge gateway packaging.
   - Outputs ready-to-copy embedding widget scripts or WhatsApp/Telegram API configurations based on selected channels.
3. **📊 Persistent Leads & Analytics Dashboard**:
   - Keeps track of all leads captured by the simulator in real-time using `localStorage` persistence.
   - Monitor conversion metrics (Bot accuracy, Active deployments, captured leads counter).
   - Filter, view complete client project scopes, and export leads as a `.json` document.
4. **💬 Interactive Live Sandbox**:
   - A mockup device containing your custom bot that updates in real-time as you tweak configurations.
   - **RAG Simulation Engine**: Converses with users querying services, pricing, or portfolio details.
   - **Form-less Leads Capture Flow**: Triggered automatically when a prospect shows intent to hire. Prompts the prospect step-by-step for Name, Email, Budget, and Scope, then updates the leads database instantly with a system message!

---

## Tech Stack & Architecture

- **Core Structure**: Semantic HTML5 & Modern CSS Grid Layouts
- **Styling**: Vanilla HSL-based design system with sleek glassmorphism, responsive scales, and modern transitions (Outfit & Inter typography).
- **Core Engine**: Object-Oriented ES6 Modular Javascript. Includes keywords-matching RAG simulator and state-machine lead capture workflow.
- **Local Dev Server**: Vite (hot-reloading enabled)

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Open your terminal in the project directory:
   ```bash
   cd "d:\Freelance service"
   ```
2. Install the lightweight development dependencies:
   ```bash
   npm install
   ```

### Launch Development Server

Run the following command to start the Vite local development server:
```bash
npm run dev
```

The terminal will provide a local address (e.g., `http://localhost:5173`). Open this URL in any modern browser to interact with your brand-new **AI Chatbot Setup Agent**!
